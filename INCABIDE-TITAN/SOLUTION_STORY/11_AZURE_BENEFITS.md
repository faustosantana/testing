# 11 — AZURE BENEFITS

## Beneficios de Azure en la historia

La RFP define Microsoft Azure como plataforma obligatoria. La narrativa debe presentar Azure como base de operacion segura, escalable y gobernable, sin entrar aun en arquitectura detallada.

## Beneficios sustentados

| Beneficio | Relacion con RFP |
| --- | --- |
| Plataforma cloud obligatoria | INCABIDE requiere Azure. |
| Escalabilidad | La RFP menciona estabilidad y escalabilidad como razones de Azure. |
| Seguridad integrada | Permite implementar MFA, WAF, DDoS, vault, cifrado y monitoreo. |
| Operacion moderna | Facilita contenedores, backups, logs y alertas. |
| Transferencia de control | Accesos completos a INCABIDE como hito. |
| Evidencias | Capturas, registros, configuraciones y reportes para aceptacion. |

## Historia Azure

El SGB deja de ser una aplicacion que simplemente "corre en un servidor" y pasa a operar como una plataforma cloud institucional: protegida, monitoreada, documentada y preparada para crecer.

## Decisiones pendientes

La narrativa debe reconocer que region, tenant, ambientes, RTO/RPO, WAF/DDoS y dimensionamiento requieren confirmacion antes de arquitectura detallada.
