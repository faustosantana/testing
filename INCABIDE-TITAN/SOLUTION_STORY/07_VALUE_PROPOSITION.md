# 07 — VALUE PROPOSITION

## Propuesta de valor

La solucion ofrece una forma segura, trazable y operable de administrar bienes bajo custodia, conectando registro, evidencia, ubicacion, decisiones, seguridad, reportes y disposicion final.

## Valor para INCABIDE

| Valor | Sustento RFP |
| --- | --- |
| Trazabilidad del bien | Registro, documentacion multimedia, auditoria y cadena de custodia. |
| Seguridad reforzada | MFA, cifrado, WAF, DDoS, vault, monitoreo y pentest. |
| Plataforma cloud | Microsoft Azure obligatorio. |
| Operacion completa | Etapa I estabiliza; Etapa II amplia modulos. |
| Toma de decisiones | Reportes, analisis y dashboards. |
| Transferencia | Documentacion, capacitacion y accesos completos. |

## Valor para PADF

- mayor control de cumplimiento;
- aceptacion por evidencia;
- entregables verificables;
- riesgos visibles;
- modularidad para contratacion progresiva;
- separacion de integraciones condicionadas.

## Valor para usuarios

- menos busqueda manual;
- informacion centralizada;
- alertas accionables;
- permisos claros;
- flujos guiados;
- reportes accesibles.

## Lo que no se promete en esta historia

- costos;
- cronogramas finales;
- funcionalidades fuera de la RFP;
- integracion PGR como obligacion con fecha fija;
- certificaciones o experiencias no verificadas.
