# 18 — PROJECT IDENTITY

## Nombre conceptual

**SGB Atlas INCABIDE**

Atlas representa vision territorial, custodia, control, ubicacion y decision basada en informacion.

## Eslogan

**Cada bien, una historia trazable. Cada decision, una evidencia.**

## Principios

| Principio | Significado |
| --- | --- |
| Trazabilidad | Todo evento relevante queda registrado. |
| Seguridad | Los datos sensibles se protegen desde el diseno. |
| Claridad | La informacion debe ser comprensible y accionable. |
| Control | Usuarios, permisos, procesos y evidencias estan gobernados. |
| Operabilidad | La plataforma debe poder administrarse y sostenerse. |
| Modularidad | La evolucion ocurre por etapas y prioridades. |

## Valores

- confianza;
- transparencia;
- responsabilidad;
- precision;
- continuidad;
- servicio publico;
- modernizacion institucional.

## Personalidad

| Atributo | Descripcion |
| --- | --- |
| Sobria | No exagera ni decora innecesariamente. |
| Segura | Transmite control y proteccion. |
| Moderna | Se siente como SaaS enterprise. |
| Institucional | Respeta el contexto publico y legal. |
| Accionable | Orienta a decisiones y proximos pasos. |

## Mensajes clave

1. El SGB modernizado acompana todo el ciclo de vida del bien.
2. Cada accion relevante deja evidencia.
3. La Direccion obtiene visibilidad ejecutiva.
4. Los operadores trabajan con flujos guiados.
5. Los auditores reconstruyen decisiones con datos.
6. Azure permite operar una plataforma moderna y segura.
7. INCABIDE recibe documentacion, capacitacion y control operativo.

## Tono narrativo

Tecnico, ejecutivo, sobrio y sustentado en requisitos. Evitar lenguaje exagerado o promesas no verificables.
