# 06 — DIGITAL JOURNEY

## Historia completa del ciclo de vida del bien

### 1. El bien llega a INCABIDE

Un bien es remitido a INCABIDE por una entidad como PGR, DGII, DGA, DNCD u otra. El operador registra el caso, la entidad remitente, los datos del bien y su clasificacion.

**Que se registra**

- caso;
- entidad remitente;
- categoria y subcategoria;
- identificador unico;
- valor o datos relevantes;
- ubicacion o referencia;
- documentos iniciales.

**Evidencia**

- documentos adjuntos;
- usuario y fecha de registro;
- codigo/QR;
- evento de auditoria.

### 2. El bien queda clasificado y localizado

El sistema organiza el bien por provincia, municipio, almacen, pasillo, seccion o referencia catastral segun corresponda.

**Controles**

- catalogos;
- listas desplegables;
- validacion de unicidad;
- geolocalizacion cuando aplique.

### 3. El bien entra en custodia

Durante la custodia, el bien puede recibir documentos, fotos, videos, cambios de ubicacion, movimientos y observaciones.

**Evidencia**

- documentacion multimedia;
- timeline;
- cadena de custodia;
- auditoria de usuarios.

### 4. El bien genera decisiones

Segun su naturaleza, el bien puede requerir contrato, seguimiento financiero, mantenimiento, subasta, donacion, devolucion o destruccion.

**Quien interviene**

- operador;
- gerente;
- area legal;
- auditor;
- administrador;
- direccion cuando hay decisiones criticas.

### 5. El bien se prepara para disposicion

El sistema valida documentos, estado, permisos y flujo de aprobacion antes de continuar.

**Controles**

- aprobaciones;
- alertas;
- documentos requeridos;
- permisos por rol;
- registro de cambios.

### 6. El bien se dispone

Puede terminar en:

- subasta/venta;
- donacion;
- devolucion;
- destruccion;
- cierre administrativo.

**Evidencia final**

- acta o documento;
- aprobacion;
- usuario responsable;
- fecha;
- resultado;
- reporte;
- auditoria.

### 7. La direccion visualiza resultados

El Dashboard Ejecutivo consolida bienes, valor, provincias, estados, alertas, subastas y procesos criticos.

## Journey resumido

```text
Recepcion -> Registro -> Clasificacion -> Custodia -> Seguimiento -> Decision -> Disposicion -> Evidencia -> Reporte
```

## Decisiones tomadas durante el ciclo

- aceptar o devolver informacion incompleta;
- aprobar movimiento;
- solicitar documento;
- cambiar estado;
- preparar subasta;
- aprobar donacion/devolucion/destruccion;
- cerrar expediente;
- escalar alerta critica.
