# 04 — THE SOLUTION

## Solucion narrativa

La solucion moderniza el SGB existente y lo convierte en una plataforma de gestion integral de bienes sobre Microsoft Azure. Mantiene la base Django/Python y PostgreSQL/PostGIS, adapta el sistema a nube, personaliza identidad y terminologia INCABIDE, incorpora seguridad reforzada y prepara el desarrollo modular de nuevas capacidades.

## Bloques de solucion

| Bloque | Historia que habilita |
| --- | --- |
| Registro de activos | El bien nace digitalmente con identificador, categoria, ubicacion y evidencia. |
| Expediente digital | Toda la informacion del bien vive en un solo lugar. |
| Documentacion multimedia | Fotos, videos y documentos quedan asociados al activo. |
| Geolocalizacion | INCABIDE entiende donde estan sus bienes. |
| Contratos y clientes | Bienes en alquiler o uso generan seguimiento contractual y financiero. |
| Subastas / ventas | La disposicion comercial se gestiona con trazabilidad. |
| Descargo / donaciones | La disposicion no comercial queda documentada y aprobada. |
| Seguridad avanzada | Usuarios, roles, MFA y permisos protegen informacion sensible. |
| Auditoria | Cada accion relevante deja rastro. |
| Reportes | La direccion toma decisiones con informacion consolidada. |
| API | El SGB queda preparado para interoperar de forma controlada. |

## Etapa I

La historia inicial es estabilizar, adaptar y desplegar:

1. analizar codigo y dependencias;
2. adaptar configuracion para cloud;
3. personalizar marca y terminologia;
4. implementar infraestructura Azure;
5. contenerizar;
6. poner en produccion;
7. documentar;
8. capacitar;
9. entregar accesos y soporte.

## Etapa II

La historia evolutiva es ampliar capacidades por modulos priorizados por INCABIDE, con mockups validados, codigo, pruebas, manuales y actas de aceptacion por modulo.
