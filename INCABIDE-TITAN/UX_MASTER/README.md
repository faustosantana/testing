# UX MASTER — INCABIDE SGB

Diseno maestro de experiencia de usuario para el Sistema de Gestion de Bienes de INCABIDE.

## Alcance

Este directorio define la experiencia, sistema visual, navegacion, componentes, pantallas, journeys y diferenciadores UX/UI del SGB como producto SaaS institucional de clase mundial.

## Fuera de alcance

- No contiene codigo frontend.
- No contiene pantallas desarrolladas.
- No contiene mockups graficos.
- No contiene imagenes generadas.
- No contiene demo.

## Referencias de calidad

Microsoft, Atlassian, Linear, Notion, Stripe Dashboard, GitHub Enterprise y Azure Portal.
