# 04 — TYPOGRAPHY

## Direccion tipografica

Tipografia limpia, altamente legible, compatible con interfaces de datos y documentos institucionales.

## Familias sugeridas

| Uso | Estilo |
| --- | --- |
| Interfaz | Sans serif moderna estilo Inter, Segoe UI o similar. |
| Datos tabulares | Numeros tabulares para KPIs, montos y codigos. |
| Documentos imprimibles | Sans serif sobria con jerarquia clara. |

## Escala

| Token | Uso |
| --- | --- |
| Display | Titulos ejecutivos y hero metrics. |
| H1 | Titulo de pantalla. |
| H2 | Secciones principales. |
| H3 | Cards y paneles. |
| Body | Texto operativo. |
| Small | Metadata, ayudas, timestamps. |
| Mono | Codigos, IDs, referencias, API. |

## Reglas

- Titulos orientados a accion: "Bienes en custodia", no "Modulo".
- KPIs con numeros grandes y etiquetas breves.
- Metadata secundaria en menor contraste.
- Codigos de caso, activo y QR con fuente monoespaciada.
- No usar parrafos largos en pantallas operativas.
- Ayudas contextuales maximo 1-2 lineas.

## Jerarquia recomendada

1. Estado o decision principal.
2. KPI o informacion primaria.
3. Contexto.
4. Acciones.
5. Detalles secundarios.

## Accesibilidad

- tamano base legible;
- interlineado amplio;
- evitar texto gris demasiado claro;
- soporte para zoom del navegador;
- no usar mayusculas extensas en lectura operativa.
