# 17 — PRINT DESIGN

## Objetivo

Los documentos imprimibles deben ser sobrios, verificables y aptos para uso institucional.

## Piezas imprimibles

- resumen de expediente;
- acta de cadena de custodia;
- reporte ejecutivo;
- listado de bienes;
- reporte de auditoria;
- acta de aprobacion;
- comprobantes y recibos;
- reportes de subasta;
- constancias de disposicion.

## Estructura de impresion

| Seccion | Contenido |
| --- | --- |
| Encabezado | Logo INCABIDE, titulo, fecha, version. |
| Metadata | Codigo, caso, responsable, estado. |
| Contenido | Datos principales y tablas. |
| Evidencia | Documentos, firmas, referencias. |
| Auditoria | Usuario, fecha de generacion, hash/folio si aplica. |
| Pie | Confidencialidad y paginacion. |

## Reglas

- blanco y negro legible;
- tablas con encabezados repetidos;
- evitar fondos pesados;
- incluir fecha de corte;
- incluir usuario generador;
- marcar confidencialidad;
- paginacion clara.

## Experiencia

Un documento impreso debe sentirse oficial, confiable y listo para expediente o revision legal.
