# 05 — ICONOGRAPHY

## Estilo

Iconografia lineal, simple, consistente y profesional. Debe parecer enterprise SaaS, no decorativa.

## Principios

- un solo estilo visual;
- grosor consistente;
- significado claro;
- compatible con texto;
- no usar iconos como unica senal;
- evitar metaforas ambiguas.

## Categorias de iconos

| Categoria | Ejemplos de uso |
| --- | --- |
| Activos | Bienes, vehiculos, inmuebles, activos financieros. |
| Legal | Casos, sentencias, documentos, aprobaciones. |
| Ubicacion | Mapa, provincia, geolocalizacion, almacen. |
| Seguridad | Candado, MFA, permisos, auditoria. |
| Operacion | Alertas, soporte, health, backup. |
| Finanzas | Valor, pago, contrato, conciliacion. |
| Acciones | Crear, editar, aprobar, rechazar, exportar, archivar. |

## Reglas de uso

- Icono + etiqueta en navegacion principal.
- Icono solo permitido en botones conocidos con tooltip.
- Iconos criticos acompanados de color y texto.
- No mezclar emojis con iconografia de sistema.
- Mantener tamano uniforme por componente.

## Iconos para estados

| Estado | Icono conceptual |
| --- | --- |
| Aprobado | Check circle |
| Pendiente | Clock |
| Critico | Alert triangle |
| Bloqueado | Lock |
| En revision | Eye / review |
| Archivado | Archive |
| Confidencial | Shield / lock |

## Iconografia ejecutiva

El Dashboard Ejecutivo debe usar iconos discretos para orientar rapidamente, pero los datos y textos deben dominar.
