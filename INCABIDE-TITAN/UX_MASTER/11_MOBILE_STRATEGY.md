# 11 — MOBILE STRATEGY

## Enfoque

Mobile debe priorizar consulta, alertas, aprobaciones simples y captura ligera. Los flujos complejos de registro, reporteria avanzada y configuracion siguen siendo desktop-first.

## Casos moviles prioritarios

- consultar expediente de bien;
- escanear o ingresar codigo/QR;
- ver alertas;
- aprobar/rechazar tareas simples;
- cargar evidencia fotografica;
- consultar mapa;
- revisar timeline;
- abrir ticket de soporte.

## Patrones responsive

| Desktop | Mobile |
| --- | --- |
| Sidebar | Bottom nav o menu compacto. |
| Tabla | Cards resumidas con filtros. |
| Panel derecho | Pantalla detalle. |
| Filtros avanzados | Sheet inferior. |
| Dashboard amplio | KPIs apilados. |
| Map + list | Alternar mapa/lista. |

## Reglas

- botones tactiles amplios;
- formularios divididos por pasos;
- guardado automatico de borradores;
- carga de archivos simple;
- busqueda siempre visible;
- acciones destructivas con confirmacion;
- modo lectura optimizado.

## Limitaciones

No se recomienda que administracion avanzada de usuarios, configuracion de catalogos o reportes complejos dependan de mobile.
