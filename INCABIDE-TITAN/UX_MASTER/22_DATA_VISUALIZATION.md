# 22 — DATA VISUALIZATION

## Objetivo

Visualizaciones claras, accionables y auditables.

## Tipos de visualizacion

| Tipo | Uso |
| --- | --- |
| KPI card | Total, valor, alertas, vencimientos. |
| Barras | Bienes por provincia, categoria, estado. |
| Lineas | Tendencias mensuales. |
| Dona | Distribucion por estado. |
| Mapa | Distribucion geografica. |
| Tabla | Detalle auditable. |
| Timeline | Historial de eventos. |
| Heatmap | Concentracion territorial o riesgo. |

## Reglas

- toda grafica debe tener titulo y periodo;
- incluir total cuando se muestre distribucion;
- permitir drill-down;
- usar leyenda clara;
- evitar 3D;
- no saturar colores;
- ofrecer tabla de respaldo;
- exportaciones auditadas.

## KPIs recomendados

- total de bienes;
- valor economico;
- bienes por estado;
- bienes por provincia;
- alertas criticas;
- proximas subastas;
- contratos por vencer;
- documentos faltantes;
- accesos fallidos;
- procesos pendientes.

## Mapa

El mapa debe permitir:

- vista nacional;
- drill-down provincia/municipio;
- filtros por categoria/estado/valor;
- clusters;
- panel lateral de bienes;
- leyenda;
- alternativa en tabla.

## Analitica avanzada

Analisis predictivo y pronosticos deben presentarse solo si existen datos y criterios aprobados. Visualmente deben diferenciarse de datos historicos confirmados.
