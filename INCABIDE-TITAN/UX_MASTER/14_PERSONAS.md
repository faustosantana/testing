# 14 — PERSONAS

## Director de INCABIDE

| Aspecto | Descripcion |
| --- | --- |
| Objetivo | Ver estado institucional y tomar decisiones. |
| Necesita | KPIs, alertas, mapa, procesos criticos. |
| Dolor | Informacion dispersa o tardia. |
| UX ideal | Dashboard ejecutivo claro y confiable. |

## Gerente operativo

| Aspecto | Descripcion |
| --- | --- |
| Objetivo | Supervisar equipos, bienes y procesos. |
| Necesita | Pendientes, vencimientos, aprobaciones, filtros. |
| Dolor | No saber que requiere accion. |
| UX ideal | Dashboard operativo priorizado. |

## Operador de activos

| Aspecto | Descripcion |
| --- | --- |
| Objetivo | Registrar y actualizar bienes correctamente. |
| Necesita | Formularios guiados, catalogos, validaciones. |
| Dolor | Errores manuales y campos confusos. |
| UX ideal | Registro paso a paso con guardado parcial. |

## Auditor / cumplimiento

| Aspecto | Descripcion |
| --- | --- |
| Objetivo | Ver trazabilidad y evidencia. |
| Necesita | Timeline, auditoria, documentos, exportaciones. |
| Dolor | Falta de historia confiable. |
| UX ideal | Centro de auditoria con filtros poderosos. |

## Administrador TI

| Aspecto | Descripcion |
| --- | --- |
| Objetivo | Mantener plataforma segura y operativa. |
| Necesita | Usuarios, permisos, monitoreo, backups, logs. |
| Dolor | Incidentes sin evidencia. |
| UX ideal | Consola de salud y administracion. |

## Usuario espectador

| Aspecto | Descripcion |
| --- | --- |
| Objetivo | Consultar informacion autorizada. |
| Necesita | Busqueda, filtros, reportes. |
| Dolor | Acceso excesivo o insuficiente. |
| UX ideal | Lectura clara sin acciones peligrosas. |
