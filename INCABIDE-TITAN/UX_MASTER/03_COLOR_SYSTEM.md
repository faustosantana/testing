# 03 — COLOR SYSTEM

## Direccion visual

Paleta sobria, institucional y moderna. Debe transmitir control, confianza, legalidad y tecnologia. Evitar colores saturados o apariencia decorativa.

## Paleta conceptual

| Rol | Color conceptual | Uso |
| --- | --- | --- |
| Azul institucional profundo | Primario | Navegacion, acciones principales, confianza. |
| Azul claro tecnico | Secundario | Enlaces, informacion, hover. |
| Gris grafito | Texto principal | Lectura profesional. |
| Gris nube | Fondos | Superficies limpias. |
| Verde control | Exito | Activo, aprobado, saludable. |
| Ambar alerta | Advertencia | Vencimientos, pendientes, atencion. |
| Rojo critico | Riesgo | Bloqueado, vencido, seguridad. |
| Violeta inteligencia | Analitica | Insights, prediccion, reportes avanzados. |

## Uso por estado

| Estado | Color | Regla |
| --- | --- | --- |
| Activo | Verde | Solo para estado positivo real. |
| Pendiente | Ambar | Requiere accion o seguimiento. |
| Critico | Rojo | Impacta cumplimiento, seguridad o vencimiento. |
| En revision | Azul | Flujo normal de aprobacion. |
| Archivado | Gris | No activo pero consultable. |

## Reglas

- No depender solo del color: agregar texto, icono o badge.
- Mantener contraste WCAG AA como minimo.
- Usar rojo solo para eventos verdaderamente criticos.
- Usar colores de graficas con leyendas claras.
- Evitar fondos oscuros en formularios largos.

## Aplicacion ejecutiva

El Dashboard Ejecutivo debe usar color como semaforo de decision:

- verde: operacion saludable;
- ambar: requiere seguimiento;
- rojo: requiere intervencion ejecutiva;
- azul: informacion institucional;
- violeta: insight analitico.
