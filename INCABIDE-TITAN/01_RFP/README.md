# 01_RFP

Carpeta para almacenar el RFP No. 5801 DRC3P, anexos, aclaraciones oficiales y comunicaciones formales relacionadas.

## Uso

- Guardar solo documentos oficiales o recibidos por canales autorizados.
- Registrar fecha de recepcion y fuente en el nombre del archivo o en una nota de control.
- No editar documentos originales; crear copias de trabajo cuando sea necesario.
