# PRESENTATION MASTER STORYBOARD — INCABIDE TITAN

## Proposito

Disenar la presentacion ejecutiva que podria utilizarse ante el comite de PADF/INCABIDE, sin crear PowerPoint, imagenes, mockups ni diapositivas finales.

## Critica tecnica obligatoria

| Pregunta | Decision |
| --- | --- |
| ¿Existe una mejor manera de hacer esta fase? | Si: disenar la presentacion como una historia ejecutiva, no como una lista de secciones tecnicas. |
| ¿Hay riesgo de retrabajo? | Si: crear slides antes de aprobar narrativa, duracion, diagramas y mensajes. |
| ¿Hay dependencias que resolver primero? | Si: confirmar informacion de Justech, referencias, equipo, certificaciones y decisiones PADF pendientes. |
| ¿Se requiere detener el enfoque? | No. El storyboard ejecutivo cumple el objetivo sin producir PowerPoint. |

## Enfoque narrativo

La presentacion debe hacer que el comite entienda tres ideas:

1. INCABIDE necesita trazabilidad institucional, no solo software.
2. El SGB puede convertirse en una plataforma segura, moderna y operable.
3. Justech propone un enfoque gobernado por evidencia, seguridad, Azure, UX y transferencia.

## Duracion objetivo

Duracion recomendada: **25 a 30 minutos**, dejando espacio para preguntas.

## Numero de diapositivas

Numero recomendado: **18 diapositivas**.

## Reglas editoriales

- No usar lenguaje comercial exagerado.
- No inventar certificaciones, experiencia ni clientes.
- No mostrar precios.
- No mostrar pantallas no aprobadas como si existieran.
- Marcar mockups como conceptuales cuando se creen en fase futura.
- Mantener estilo sobrio, moderno y Enterprise.
- Priorizar claridad sobre cantidad de texto.
- Cada slide debe responder una pregunta del comite.

## Dependencias antes de crear PowerPoint

1. Aprobar storyboard.
2. Definir duracion final.
3. Aprobar si se usaran mockups conceptuales.
4. Obtener logos autorizados.
5. Definir estilo visual final.
6. Confirmar informacion Justech: equipo, referencias, certificaciones.
7. Confirmar que afirmaciones de capacidad tienen evidencia.
8. Seleccionar diagramas que se convertiran a visual.

## Fuera de alcance

- No se crea PowerPoint.
- No se crean diapositivas finales.
- No se crean mockups.
- No se generan imagenes.
- No se desarrolla demo.
- No se incluye oferta economica.
