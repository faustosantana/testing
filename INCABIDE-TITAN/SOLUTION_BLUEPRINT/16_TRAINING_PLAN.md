# 16 — TRAINING PLAN

## Objetivo

Definir el plan conceptual de transferencia de conocimiento y capacitacion para que INCABIDE pueda operar y administrar el SGB.

## Audiencias

| Audiencia | Necesidad |
| --- | --- |
| Equipo tecnico INCABIDE | Arquitectura, contenedores, backups, accesos, monitoreo y soporte. |
| Administradores funcionales | Usuarios, roles, permisos, catalogos y reportes. |
| Usuarios operativos | Registro, consulta, documentos, flujos y reportes. |
| Direccion / supervisores | Dashboards, indicadores y trazabilidad. |

## Capacitacion tecnica minima RFP

La RFP exige una sesion minima de 4 horas para el equipo tecnico de INCABIDE, con grabacion o presentacion PDF y lista firmada con minimo 2 tecnicos.

## Modulos de capacitacion propuestos

| Modulo | Contenido |
| --- | --- |
| Introduccion SGB | Objetivo, alcance, roles y ciclo de vida de activos. |
| Operacion tecnica | Contenedores, variables, inicio/parada/reinicio y logs. |
| Seguridad | MFA, roles, permisos, secretos y auditoria. |
| Backup/restore | Procedimientos, evidencias y validacion. |
| Soporte | Reporte de incidentes, SLA y escalamiento. |
| Uso funcional | Registro, contratos, disposicion, reportes y documentos. |
| Administracion | Usuarios, catalogos, configuracion y permisos. |

## Materiales

- presentacion PDF;
- grabacion;
- manual tecnico;
- manual usuario;
- guias rapidas;
- FAQ;
- runbooks;
- ejercicios practicos;
- checklist post-capacitacion.

## Validacion de aprendizaje

- asistencia firmada;
- preguntas y respuestas;
- ejercicio guiado;
- confirmacion escrita de autonomia tecnica;
- encuesta de retroalimentacion;
- lista de pendientes.

## Portal de capacitacion como diferenciador

Como complemento no obligatorio, la solucion puede incluir un centro de aprendizaje con:

- videos cortos;
- manuales descargables;
- guias por rol;
- FAQ;
- checklists;
- actualizaciones por version.
