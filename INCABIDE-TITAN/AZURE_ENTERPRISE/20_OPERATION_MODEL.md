# 20 — OPERATION MODEL

## Objetivo

Definir operacion diaria de la plataforma Azure del SGB.

## Rutinas

| Frecuencia | Actividad |
| --- | --- |
| Diaria | Revisar alertas, disponibilidad y errores. |
| Semanal | Revisar backups, seguridad, capacidad y costos. |
| Mensual | Revisar accesos, vulnerabilidades, retencion y salud. |
| Por release | Validar despliegue, rollback y evidencias. |
| Por incidente | Clasificar, atender, cerrar y documentar. |

## Roles

- Administrador Azure.
- DevSecOps.
- DBA/PostgreSQL.
- Soporte aplicacion.
- Seguridad.
- Responsable INCABIDE.

## Entregables operativos

- runbook Azure;
- matriz de accesos;
- reporte de salud;
- evidencias de backup;
- reporte de incidentes;
- registro de cambios;
- inventario de recursos.

## Pendiente de validacion

- Quien opera la suscripcion.
- Responsables finales INCABIDE.
- Modelo de escalamiento.
- Herramienta de tickets.
