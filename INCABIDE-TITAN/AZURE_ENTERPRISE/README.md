# AZURE ENTERPRISE ARCHITECTURE — INCABIDE TITAN

Arquitectura Microsoft Azure Enterprise conceptual para el SGB de INCABIDE.

## Alcance

Disenar una arquitectura real y defendible basada en los requisitos de la RFP: Azure obligatorio, contenedores Docker, PostgreSQL 14+ con PostGIS/unaccent, almacenamiento de medios, seguridad reforzada, monitoreo, backups, DRP, WAF, DDoS, VPN, MFA, RBAC, auditoria y soporte.

## Fuera de alcance

- No contiene Terraform.
- No contiene Bicep.
- No contiene Docker Compose.
- No despliega infraestructura.
- No contiene diagramas ni imagenes.
- No contiene precios.

## Regla de decisiones

Toda decision dependiente de PADF/INCABIDE se marca como `PENDIENTE DE VALIDACION`.
