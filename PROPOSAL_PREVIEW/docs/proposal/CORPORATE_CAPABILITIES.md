# CORPORATE CAPABILITIES — JUSTECH SRL

## Objetivo

Documentar las capacidades corporativas confirmadas de Justech SRL para su uso en la Oferta Tecnica, sin agregar capacidades no verificadas.

## Capacidades confirmadas

| Capacidad | Aplicacion potencial al proyecto INCABIDE |
| --- | --- |
| Desarrollo de software | Adaptacion y evolucion del SGB, sujeto al alcance de la RFP. |
| Microsoft Azure | Diseno y soporte de arquitectura cloud en la plataforma obligatoria de la RFP. |
| AWS | Experiencia cloud complementaria, sin sustituir Azure para este proyecto. |
| Microsoft 365 | Experiencia en servicios Microsoft, politicas y administracion de plataforma. |
| Redes empresariales | Soporte conceptual para conectividad, segmentacion, VPN/firewall y operacion de red. |
| Infraestructura | Capacidad para entender despliegues, ambientes y operacion tecnologica. |
| Ciberseguridad | Alineacion con controles de seguridad, acceso, monitoreo y proteccion de datos. |
| ERP Odoo | Experiencia en soluciones empresariales, flujos operativos y procesos administrativos. |

## Relacion con la RFP

Estas capacidades se conectan con los frentes de trabajo exigidos por la RFP:

- adaptacion tecnica del SGB;
- despliegue obligatorio en Microsoft Azure;
- infraestructura cloud;
- redes, firewall, VPN y seguridad;
- gestion segura de accesos;
- soporte a plataformas empresariales;
- evolucion modular de funcionalidades.

Estas capacidades pueden presentarse como capacidades corporativas confirmadas. No deben convertirse en afirmaciones de certificacion, partnership especializado, experiencia sectorial especifica o resultado medible si no existe evidencia confirmada.
